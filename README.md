# call_to_exist_redirector
A DLL file/ASI Hook compiled in Visual Studio IDE using MSVC to redirect game assets to load from mods folder

# Installation
Download the `CtE Redirector.asi` and `dinput8.dll` from Releases to your Tokyo Ghoul: re [CALL to EXIST] game folder next to the exe.

Make a `mods` folder next to the game exe, and you would drop your modded files there [without the last underscore + type] 
 - e.g.: if the filename is c001_tex_a_re_tex as extracted using the [GUI Tool](https://www.nexusmods.com/tokyoghoulrecalltoexist/mods/2?tab=files), remove the `_tex` from it

`btx Textures and BML Models only supported for redirection now`
