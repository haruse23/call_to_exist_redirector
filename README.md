# call_to_exist_redirector
A DLL file/ASI Hook compiled in Visual Studio IDE using MSVC to redirect game assets to load from mods folder

# Installation
Download the `CtE Redirector.asi` and `dinput8.dll` from Releases to your Tokyo Ghoul: re [CALL to EXIST] game folder next to the exe.

Make a `mods` folder next to the game exe, and you would drop your modded files there 

Supported filetypes for redirection:
 - btx Textures
 - BML Models
 - _BMA
 - _BMD
